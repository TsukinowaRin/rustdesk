スキルの追加候補と、決めてほしいこと

2026-09-23 ／ 今日 5 本を入れて 17 本になりました。ここから先の候補（Hugging Face、superpowers）と、文書の道具について、あなたの判断が要ります。返し方の例は最後にあります。

1. 今日入れた 5 本（済み）

名前何をするか別に要る道具
mcp-builderMCP サーバー（エージェントに新しい道具を足す仕組み）を作る手引きなし
docxWord を読む・作る・直すLibreOffice、npm の docx（読むだけなら python-docx か markitdown）
xlsxExcel を読む・作る・直すopenpyxl、LibreOffice
pptxPowerPoint を読む・作る・直すpython-pptx、markitdown、npm の pptxgenjs、LibreOffice
pdfPDF を読む・結合・分割・作る・文字起こしpypdf、pdfplumber、reportlab。画像の PDF は pdftotext・tesseract

注意 2 つ。

  • docx・xlsx・pptx は、同じ 1.2 MB の部品（Office の書式の定義ファイル）を 3 重に持っています。上流の形のまま入れたので、スキル全体は 4.0 MB になりました。
  • スキルは「どの道具でどうやるか」を教えるだけで、道具そのものは別に要ります。この機械には LibreOffice も pypdf も 1 つも入っていません。あなたの言う「PDF を読むために道具を入れていたエージェント」は、これからも道具を入れることになります。ただし、どれを入れるかはスキルが正しく指示するので、迷いと失敗は減ります。

2. 文書の道具を一括で入れる命令（提案）

python3 harness/setup.py docs-tools のような命令を 1 つ足し、要る物を版を固定して一括で入れられるようにします。自動では入れません（人が打ちます）。

  • pip: pypdf pdfplumber reportlab openpyxl python-docx python-pptx markitdown
  • OS の道具（別途）: LibreOffice、poppler（pdftotext）、tesseract（文字起こし）。これらは管理者の窓を通します
  • npm: docx pptxgenjs（作る側だけ。読むだけなら不要）

入れると、スキルが「道具が無い」で止まらなくなります。

6. 決めてほしいこと

  1. 文書の道具を一括で入れる命令を setup.py に足しますか。（入れる / 入れない）
  2. hf-cli を 1 本入れますか。（入れる / 入れない）
  3. superpowers から、上の 5 本を入れますか。外したい物があれば名前を。（5 本とも / 一部 / 入れない）

どれも、取り込む前に同じ検査（下見 → 無編集で写す → 出どころと hash を記録）を通します。

返し方の例: 「1 入れる、2 入れる、3 は brainstorming 以外」

正本は harness/skills.json（出どころ・hash）と docs/PLAN.md。今のスキルの一覧は docs/reports/2026-09-23_skills.html。数字は 2026-09-23 の実測。
