1. 使い始め方（新しい作業場で）

要る物は Python 3.11 以上と git。担い手に使う CLI にはサインインしておく。あとは docs/HARNESS.md の冒頭「入れてから最初の 1 件まで」のとおり。

unzip harness-v3.1.0.zip && cd harness-v3.1.0
git init && git add -A && git commit -m init          # 担い手の作業木は HEAD から作る
python3 harness/check.py                                # 点検（形 8 項目 + 試験）
python3 harness/setup.py status                         # 「まだ」を書いてある命令で済ませる
  #   通知:   python3 harness/setup.py notify skip|off|new|existing|selfhost
  #   台帳:   python3 harness/judgment.py init --new   または  init --from <既存の台帳の URL か path>
  #   編成:   cp harness/team.example.json .loop/team.json  → 人と決める（得意不得意は書かず、測る）
python3 harness/delegate.py new "題名" --member <名>   # 依頼書の枠 → 目的・受け入れ条件・触ってよい場所を書く
python3 harness/delegate.py run T-…                     # 担い手が別の作業木で動く。報告は .loop/tasks/T-…/report-*.md
python3 harness/delegate.py adopt T-…                   # 合格なら取り込む（作業木で commit → 本流へ merge）
python3 harness/dashboard_watch.py --serve 100.x.y.z:8765   # 見張り: 変化があったら描き直す。私設の網のスマホから見る

秘密は repo に入れない。担い手にだけ渡す環境変数（例: CLIProxyAPI の鍵）は .loop/worker.env に。Telegram は .loop/telegram.env に token と chat ID。どちらも守りが読み書きを止める。

4. 今日の改善の輪で直した物（要点）

  • 守り: 担い手が守り自身と本体の木を書き換えられた穴、別の担い手を起こせた穴、git checkout -- で変更を消せた穴を塞ぎ、3 往復の独立の確認で閉じた。誤検知 2 つ（/dev/null、入れ子の repo）も直した。
  • 担い手へ回す仕組み: stats の嘘（報告なしも成功）、守りの跡、費用、adopt、試験の隔離、枠切れの自動再試行、probe、worker.env、guard: edit（守りを直す依頼だけの例外）。
  • 文書: 新規利用者の通し 2 回で見つかった古い記述と穴を直し、HARNESS.md の冒頭に「入れてから最初の 1 件まで」。AGENTS.md は 5.9 KB → 4.1 KB（指示役だけの決まりは leader skill へ）。
  • ダッシュボード: 材料の JSON、受信箱、Telegram の橋、見張り、私設の網で配る、見た目の作り直し（「文字ばっかりで読みづらい」）。
  • 台帳: 作業場をまたいで共有（あなた専用の非公開 repo に本物で push 済み。配布物からは参照しない）。割り振りは 人 → 台帳 → 測定。
  • Codex の経路: Codex / omp / dsh の 3 本とも CLIProxyAPI 経由（2 アカウントを束ねる）。担い手にだけ渡す鍵は .loop/worker.env。枠切れは自動で 1 時間後に再試行。
  • 中継 hub: 1 つのアプリから複数の作業場へ（設計 docs/design/HUB.md）。Telegram の設定は全体の置き場に 1 回だけ。
  • 取り込んだ skill: test-audit（openclaw、無編集）、consulting-pptx-skill（carnot-tech。Claude Code 専用の言い回し 3 か所と Chrome の path だけ、あなたの許可で最小限を改変。上流の hash と差分は skills.json）。27 本が 9 CLI すべてから見えて使えることを実測（docs/verification/2026-09-26_skills-all-clis/）。
