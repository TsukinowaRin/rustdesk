# DESIGN（欧文 UI 向けテンプレート）

この文書は、このプロダクトの UI の見た目を 1 か所に決めておく正本である。
UI を新しく作るとき、部品を足すとき、見た目で迷ったときに読む。
各節の数値は既定値であり、根拠があれば変えてよい。変えたらこの節を更新する。

この版は欧文が主の UI 用。数値はアセンダ〜ディセンダや x-height に依存するので、採用フォントに合わせて詰め直す。

## 雰囲気

＜この UI の印象を 1 文で書く。例: 余白を広く取った読み手中心の文書ツール＞
強く見せる要素を 1 つ決め、残りは静かに保つ。
装飾は内容を伝える装置だけに限る。

## 配色と役割

色は役割で管理する。背景 / 前景 / 主色 / 補助 / 警告 / 成功の 6 つの役割に、自分の色を当てる。
本文は背景と 4.5:1 以上の明るさ差を持たせる。大きな太字は 3:1 まで下げられる。
状態（エラー・成功）を色単独で示さず、必ず文字か記号を添える。

## 文字の決まり

欧文が主の前提。
本文は 16px 以上。行間は行の長さと連動させる: 1 行 45〜75 文字なら行間 1.4〜1.5。行が長くなるほど行間を広げる。
行の長さは 75 文字を超えない。本文は 60〜70 文字を基準にする。
字面の大きさ（x-height）が小さい書体は、本文なら 17px 相当まで上げて読みやすさを保つ。
大文字だけの並びは使わない。強調はセンテンスケースのまま太字や重さで示す。
字詰め（tracking）は小見出しでも -0.02em を超えて詰めない。本文は既定のまま。
書体は 2 種類まで。本文と見出しの役割を 1 行でこの節に書く。

## 余白と配置

余白の段階は 4 / 8 / 16 / 24 / 40px から選ぶ。中途半端な値を混ぜない。
基本の配置は左揃え。両端揃え（justify）は使わない。
本文の幅は上限を決め（例: 680px）、画面幅に合わせて伸ばさない。

## 部品の見た目

ボタン・入力欄・カードごとに、角の丸さ・線の太さ・内側の余白を決めて統一する。
角の丸さは全部品共通で 1 つの値（例: 4px）から始めるのが既定。
バリエーション（主 / 無効 / 危険）の差は色でなく線の太さでも示す。

## 影と奥行き

影の型は 2 段階まで。それ以上増やさない。
浮かせるのは重なりを伝えるときだけ（メニュー・ダイアログ）。飾りで浮かせない。
境界の表現は線と影を併用しない。どちらか主の 1 つを決める。

## 動き

自動で動く演出は最初の表示 1 回だけ。各部品ごとに撒かない。
操作への応答（開く・確認する・元に戻す）は 150〜250ms で変化を見せる。
ユーザーが動きを減らす設定にしていたら、装飾の動きは止める。

## 画面幅

3 つの区切り（例: 640px / 1024px）で作り分ける。各区切りの配置先は節末に書く。
幅が狭いときは縦の並びに統一し、横並びの折り返しで誤読させない。
単語の分かち書きを活かし、ハイフネーションは本文に使わない。
タップの当たりは 44px 角以上を保つ。

## 使いやすさ（アクセシビリティ）

操作にはすべてキーボードで届き、フォーカス位置を見える型（例: 2px の線）で示す。
入力欄・エラー・リンクは色だけで区別しない。ラベル・下線・記号を添える。
画像には内容に応じた代替文を置く。装飾データは代替文なしで隠す。
