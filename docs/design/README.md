# 見た目の正本（DESIGN）

UI を作るときに読む。**2 本のうち、作るものに合う 1 本を選んで repo の根へ写し、`DESIGN.md` として使う。**

| ファイル | 向き |
|---|---|
| `DESIGN.ja.md` | 日本語が主の画面。和文と欧文が混ざる前提（行間は広め、長体をかけない、禁則、英数字の前後の扱い） |
| `DESIGN.intl.md` | 欧文が主の画面（1 行 45〜75 文字と行間の連動、x-height、大文字の扱い、字詰めの上限） |

- どちらも**ひな形**。色は役割（背景 / 前景 / 主色 / 補助 / 警告 / 成功）と明るさの差だけが書いてあり、具体的な色は使う人が入れる。
- 数値は既定値。根拠があれば変えてよい。変えたらその節を直す。
- 作風の指針（AI が作ったと分かる見た目を避ける）は `.agents/skills/frontend-design/SKILL.md`。**食い違ったら `DESIGN.md` が優先。**
- 画面の動作を確かめるときは `.agents/skills/webapp-testing/SKILL.md`。
