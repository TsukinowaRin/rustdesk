# DESIGN（日本語 UI 向けテンプレート）

この文書は、このプロダクトの UI の見た目を 1 か所に決めておく正本である。
UI を新しく作るとき、部品を足すとき、見た目で迷ったときに読む。
各節の数値は既定値であり、根拠があれば変えてよい。変えたらこの節を更新する。

## 雰囲気

＜この UI の印象を 1 文で書く。例: 静かで余白の多い業務ツール＞
１か所だけ強く見せる要素（例: 見出し）を決め、ほかは控えめにする。
装飾や記号は、内容を伝えるときだけ使う。

## 配色と役割

色は役割で管理する。背景 / 前景 / 主色 / 補助 / 警告 / 成功の 6 つの役割に、自分の色を当てる。
役割ごとに calc でなく実値を決める。
本体の文字は背景と 4.5:1 以上の明るさ差を保つ。大きな太字は 3:1 まで下げられる。
色だけで状態（エラー・成功）を示さない。必ず文字か記号を添える。

## 文字の決まり

和文が主で欧文が混ざる前提。
本文は 16px 以上、行間は 1.8 程度。見出しは 1.4 などやや詰める。
行の長さは 35〜45 文字（和文換算）を超えない。
字間は既定のまま。字詰め（長体・アキ調整）は使わない。禁則は OS・ブラウザの既定に任せる。
明朝は本文読みに、ゴシックは見出し・ラベル・ボタンに使う。混在は最小限にする。
英数字は前後に半角スペースを入れる。数字の桁区切りや単位の書式はこの節に追記して統一する。
Web フォントは和文 1 書体 + 欧文 1 書体まで。用途が重ならないよう役割を分ける。

## 余白と配置

余白の段階は 4 / 8 / 16 / 24 / 40px から選ぶ。中途半端な値を混ぜない。
基本の配置は左揃え。中央揃えは見出しと完了画面だけ。
本文の幅は上限を決め（例: 720px）、画面幅に合わせて伸ばさない。

## 部品の見た目

ボタン・入力欄・カードなど主要部品ごとに、角の丸さ・線の太さを決めて統一する。
角の丸さは全部品共通で 1 つの値（例: 4px）から始めるのが既定。
バリエーション（主 / 無効 / 危険）ごとの差は色でなく線の太さでも示す。
影は部品ごとに自由に付けない。必要なら次の「影と奥行き」の型を使う。

## 影と奥行き

影の型は 2 段階まで（例: 薄い落下影と、浮かんだ状態の影）。それ以上増やさない。
浮かせるのは重なりを伝えるときだけ（メニュー・ダイアログ）。飾りで浮かせない。
境界の表現は線と影を併用しない。どちらか主の 1 つを決める。

## 動き

自動で動く演出は、最初の表示 1 回だけ。各部品ごとに撒かない。
操作への応答（開く・確認する・元に戻す）は 150〜250ms で変化を見せる。
ユーザーが動きを減らす設定にしていたら、装飾の動きは止める。

## 画面幅

3 つの区切り（例: 640px / 1024px）で作り分ける。各区切りの配置先は節末に書く。
幅が狭いときは、縦の並びに統一する。横並びの省略や折り返しで誤読させない。
タップの当たりは 44px 角以上を保つ。

## 使いやすさ（アクセシビリティ）

操作にはすべてキーボードで届き、フォーカス位置を見える型（例: 2px の線）で示す。
入力欄・エラー・リンクは色だけで区別しない。ラベル・下線・記号を添える。
画像には内容に応じた代替文を置く。装飾データは代替文なしで隠す。
